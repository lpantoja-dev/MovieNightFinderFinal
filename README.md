# 🎬 Movie Night Finder Final

## Overview

Movie Night Finder is a React Native mobile application developed using Expo for the University of Oklahoma Mobile Devices Software Development course.

The application helps users discover nearby movie theaters, view theater information, navigate using an interactive map, write reviews, save reviews to Firebase Firestore, and receive local notifications reminding them about movie night.

---

## Features

- Home screen with navigation
- Interactive map with movie theater locations
- Theater details screen
- Write, edit, and delete reviews
- Firebase Firestore database integration
- Local push notifications
- Modern dark-themed user interface
- React Navigation between multiple screens
